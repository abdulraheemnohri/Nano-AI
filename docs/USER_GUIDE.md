# User Guide

Nano AI is a lightweight local assistant using Qwen3 4B-Thinking-2507. The UI exposes Talk, Memory, Learning, Skills, Tools, Knowledge, Web Research, Automation & Agents, Model, Settings and System. Optional voice/browser assets are installed with `nano-ai setup-extras`.

Explicit learning examples include: Remember that I prefer Urdu; My name is ...; I like ... . Imported knowledge is stored as local searchable memory.

Nano intentionally does not browse, execute shell commands, control devices, use arbitrary external tools, or silently retrain model weights.
